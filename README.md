# My To-Do List

A simple to-do list app built with plain HTML, CSS and JavaScript — my first learning project.

## Features
- Add tasks
- Mark tasks as done
- Delete tasks
- Filter: All / Active / Done
- Clear all done tasks
- Tasks are saved in the browser, so they stay after a refresh

## How to run
Open `index.html` in any web browser. No installation needed.

## Files
- `index.html` — the structure of the page
- `style.css` — how it looks
- `script.js` — how it works
